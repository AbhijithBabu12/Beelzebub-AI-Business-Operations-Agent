# Beelzebub

AI-powered business operations agent for small retail and distribution businesses.

## Vision

Beelzebub helps business owners understand their operations, identify
problems, and execute routine tasks through controlled AI-assisted workflows.

## Initial Capabilities

- Business intelligence
- Inventory monitoring
- Low-stock detection
- Supplier comparison
- Purchase order preparation
- Overdue invoice monitoring
- Customer reminder drafting
- Daily operational briefings
- Human approval and audit logging

## Technology Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

### Backend
- Python
- FastAPI
- Pydantic
- SQLAlchemy
- Alembic

### Database
- PostgreSQL

### AI
- LangGraph
- Configurable hosted LLM API

### Testing and Deployment
- pytest
- Docker
- GitHub

## Development Status

Currently in project setup and product specification.

No application functionality has been implemented yet.

## Development Principles

- Database records are the source of truth.
- Business calculations use deterministic Python functions.
- AI-generated outputs are validated.
- Consequential actions require explicit human approval.
- Important actions are recorded in audit logs.
